# 인슈런스 석세스 프로그램

보험 전문가를 위한 성장 관리 앱 (프로토타입)

## 기능
- 시작 화면 · 로그인
- 홈: 업적 관리, 기간별 실적, 월별 추이
- 리쿠르팅: 파이프라인, 후보자 단계 관리
- 고객관리: 하는 일 · 수입 · 생일 · 결혼기념일 · 수술일 · 퇴원일 · 연락일, D-day 알림
- 성과분석: 목표 달성률, 팀 랭킹
- 더보기: 팀 관리, 진급 관리, 다크 모드, 알림 설정, 로그아웃

## 배포 (GitHub Pages)
1. 이 폴더의 파일을 저장소 루트에 업로드
2. Settings → Pages → Branch: `main` / `root` → Save
3. `https://<아이디>.github.io/<저장소이름>/` 에서 확인
